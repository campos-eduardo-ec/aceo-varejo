# Aeroportos BR – Brazilian Shops (with products)

Independent source and packaged assets for [Steam Workshop item 3829861554](https://steamcommunity.com/sharedfiles/filedetails/?id=3829861554).

## Requirements

Requires Airport CEO. This native data pack does not require BepInEx, Mod Loader, another Aeroportos BR pack, or another repository. Its JSON definitions, icons and mod artwork are contained in `mod/AeroportosBR-Varejo/`.

## Install

Subscribe to the Workshop item, activate it in the game's Mods menu and restart. To install this checkout manually instead, copy the entire `mod/AeroportosBR-Varejo` folder into your Airport CEO user-data `Mods` directory (on Windows: `%APPDATA%/Apoapsis Studios/Airport CEO/Mods/`). Activate and restart. Use one copy only: do not enable both a local copy and its Workshop equivalent.

The game remains an external requirement: no game binaries, aircraft models or game source are included. The full pack description, supported content and limitations are in `mod/AeroportosBR-Varejo/ModData.json` and the Workshop page.

## Edit and package

Edit the JSON and PNG files in this repository; no build step or shared repository is required. Keep filenames consistent with JSON references. Copy the pack folder as described above to test in the game. Changes on GitHub do not update Steam automatically.

For a separately published fork, generate a new mod GUID, reset `publishedFileId` to `0`, and choose a distinct name. Do not publish over the original item's ID. Review third-party asset rights before redistributing modified artwork.
